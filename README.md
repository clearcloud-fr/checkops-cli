# CheckOps CLI

Command-line client for [CheckOps](https://checkops.eu): send SBOMs and scanner results to CheckOps, and run a cloud configuration audit with your own read-only keys.

## Install

```sh
curl -sSfL https://checkops.eu/install.sh | sh
```

Prebuilt binaries for Linux (x86_64, arm64) and Windows are published in the [Releases](https://github.com/clearcloud-fr/checkops-cli/releases), with a `SHA256SUMS` file to verify them. macOS binaries are not published yet: use the Docker image in the meantime.
